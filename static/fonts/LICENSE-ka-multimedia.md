# ka-multimedia

Applies to `ka-multimedia.woff2` and `ka-multimedia.woff` in this directory.

`ka-multimedia` is **Kanji alive's own icon font**. It supplies the multimedia glyphs
in the interface — play, pause and step — including the button beside every example
compound (`.icon-play`, `.icon-pause`, `.icon-step-left`, `.icon-step-right`).
